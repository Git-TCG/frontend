# Repo TCG 웹

API와 같은 Origin의 `/api`를 사용하는 Vite·TypeScript 화면입니다. 로그인, 수집 상태, 컬렉션, 7장 덱, 체험 덱, 대전, 발견, 관리자 기능을 제공합니다. 실행은 `../backend/README.md`를 참고하세요.

로컬 정적 빌드 확인: `npm ci && npm run build`.
